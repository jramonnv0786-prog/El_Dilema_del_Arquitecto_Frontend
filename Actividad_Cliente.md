1. "La Startup de Micro-interacciones"
Mi recomendación para esta pequeña empresa: Es usar tecnología HTML5 para estructura web,CSS diseño y JavaScript para interactividad mínima con el usuario. Por último, alojamiento web gratuito en GitHub.

2. "El Clon de Figma Corporativo"
Para hacer la imitación de figma: Lo óptimo es utilizar WebAssembly, porque permite ejecutar en el navegador de manera eficiente, la velocidad es comparada a una app instalada en el ordenador.

3. "El nuevo Home Banking de un Banco Internacional"
Mi recomendación es: Framework Angular (Typescript) por su tipado estático. Por último, control de versiones GitHub para orden de código.
